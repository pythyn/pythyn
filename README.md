### 🚀 Projects

* **[risforge](https://github.com/pythyn/risforge)** — High-performance Python tool for cleaning, deduplicating, and enriching RIS bibliographic metadata in systematic reviews.

  ![Python](https://img.shields.io/badge/Python-3.10%2B-3776AB?style=for-the-badge&logo=python&logoColor=white) ![Qt](https://img.shields.io/badge/Qt-PySide6-41CD52?style=for-the-badge&logo=qt&logoColor=white) ![Pytest](https://img.shields.io/badge/Pytest-Passing-0A85EA?style=for-the-badge&logo=pytest&logoColor=white) ![GitHub Actions](https://img.shields.io/badge/GitHub_Actions-CI-2671E5?style=for-the-badge&logo=githubactions&logoColor=white) ![Format](https://img.shields.io/badge/Format-RIS-6F42C1?style=for-the-badge) ![License](https://img.shields.io/badge/License-MIT-2EA44F?style=for-the-badge)

* **[pdfxz](https://github.com/pythyn/pdfxz)** — Simple terminal-based PDF compression tool with an interactive TUI and CLI interface powered by Ghostscript. Compress single files or entire folders with safe, configurable quality profiles.

  ![Python](https://img.shields.io/badge/Python-3.10%2B-3776AB?style=for-the-badge&logo=python&logoColor=white) ![Textual](https://img.shields.io/badge/Textual-TUI-1F8ACB?style=for-the-badge) ![Ghostscript](https://img.shields.io/badge/Ghostscript-PDF_Compression-444444?style=for-the-badge) ![Pytest](https://img.shields.io/badge/Pytest-Passing-0A85EA?style=for-the-badge&logo=pytest&logoColor=white) ![CLI](https://img.shields.io/badge/Interface-CLI%20%2B%20TUI-6F42C1?style=for-the-badge) ![License](https://img.shields.io/badge/License-MIT-2EA44F?style=for-the-badge)

* **[CamCog](https://github.com/pythyn/camcan-cognitive-extractor)** — Lightweight Python tool for extracting and merging behavioral and cognitive metrics from BIDS-compliant CamCAN `*_summary.txt` files into analysis-ready CSV datasets.

  ![Python](https://img.shields.io/badge/Python-3.6%2B-3776AB?style=for-the-badge&logo=python&logoColor=white) ![Dependencies](https://img.shields.io/badge/Dependencies-Zero-2EA44F?style=for-the-badge) ![Format](https://img.shields.io/badge/Format-BIDS-6F42C1?style=for-the-badge) ![Data](https://img.shields.io/badge/Data-CamCAN-F38400?style=for-the-badge) ![CSV](https://img.shields.io/badge/Output-CSV-217346?style=for-the-badge&logo=microsoftexcel&logoColor=white) ![License](https://img.shields.io/badge/License-MIT-2EA44F?style=for-the-badge)

* **[RT Dose Segmentation](https://github.com/pythyn/rt-dose-segmentation)** — Python toolkit for extracting exclusive radiotherapy dose-band masks from NIfTI RT Dose volumes and generating ready-to-view 3D Slicer visualization scenes.

  ![Python](https://img.shields.io/badge/Python-3.7%2B-3776AB?style=for-the-badge&logo=python&logoColor=white) ![NumPy](https://img.shields.io/badge/NumPy-Array_Computing-013243?style=for-the-badge&logo=numpy&logoColor=white) ![NIfTI](https://img.shields.io/badge/Format-NIfTI-6F42C1?style=for-the-badge) ![3D Slicer](https://img.shields.io/badge/Visualization-3D_Slicer-F39C12?style=for-the-badge) ![Radiotherapy](https://img.shields.io/badge/Domain-Radiotherapy-CC3333?style=for-the-badge) ![License](https://img.shields.io/badge/License-MIT-2EA44F?style=for-the-badge)
